Para empezar desde cero

No necesitas saber programar para comenzar.

El curso está pensado para adolescentes, jóvenes y adultos sin experiencia previa. Aprenderemos a construir interfaces, darles comportamiento y resolver problemas con lógica.

La idea no es memorizar un lenguaje: es comprender qué estás haciendo, detectar errores y terminar con una pequeña aplicación web que puedas modificar y publicar.

Lo que exploraremos

De una página vacía a un proyecto propio.

Una ruta de aprendizaje por proyectos, con retos prácticos desde las primeras clases.

Bloque 01

Tu primera interfaz

Estructura con HTML, estilos con CSS, organización de archivos y uso básico de VS Code.

Bloque 02

Que las cosas pasen

JavaScript, eventos, variables y funciones para agregar interacción a la web.

Bloque 03

Aprender a resolver

Condiciones, ciclos, arreglos, objetos, diagramas y depuración aplicados a retos sencillos.

Bloque 04

Tu proyecto publicado

Integrar una aplicación web pequeña, revisar su funcionamiento y compartirla en internet.
